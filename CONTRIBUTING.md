# Contributing

1. Branch from `main`.
2. Run `pnpm setup` once, then `pnpm dev`.
3. Before you open a pull request, run `pnpm lint` and `pnpm test` from the repo root.
4. Keep the scope: BILLIONS shows information only. Pull requests that add trading, order routing, accounts or portfolio features will not be merged.
5. UI work follows `web/DESIGN.md` (tokens, copy rules, icons, motion).
